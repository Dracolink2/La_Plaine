# La_Plaine
La Plaine est un jeu Minecraft Like développer par une personne avec deux comptes différents.
La Plaine est certes faite avec de l'IA, mais les idées viennent d'un humain, une partie du code au niveau des blocks, items, biomes et dimensions viennent d'un humain, et les assets viennent tous d'un humain.

La Plaine est un Minecraft like, voici où trouver tout ce dont vous pouvez avoir besoin :
Le launcher du jeu qui vas vous permettre de lancer le jeu dans ces dernières versions sans rien installer ce trouve dans la branche principale.
Chaque version à sa propre branche, nommé uniquement avec les chiffres de versions.
les messages se trouvent dans la branche "messages".
Toutes les versions chacune mise en ZIP sont dispo dans la branche versions.
et d'autres branches pourront exister dans le future sans être mises ici.


# sur cette branche :
vous trouverez le launcher du jeu qui vas vous permettre de lancer la plupart des versions du jeu facilement, la version open source du Launcher contient moins de bugs que la version EXE, et seras largement plus mis à jour que la version EXE.
