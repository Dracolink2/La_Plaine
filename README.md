La toute première version publié de La Plaine, elle est pas complète, y'a rien, les systèmes y sont pas ouf, y'a globalement rien à faire à part se balader.

Mais !!, les versions "remak" de La Plaine sont là pour ça, redonner un coup de nouveau aux anciennes versions, pas forcement juste les updates direct avec toutes les dernières fonctionnalités, mais au moins ajouter les biomes, et blocks qui n'utilisent pas de système complexe.
Cette version a déjà un remak, la vague de remak n°1, qui passe pour le changement notable direct du numéro de version, où le petit 0 à la fin deviens un 1.
Les versions remak seront donc maintenus plus longtemps que les versions de base, car La Plaine évolue rapidement.
